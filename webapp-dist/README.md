# 无人机专家 (Drone Expert) - WebApp 独立部署包

本工程是一套纯静态、无服务器依赖、现代响应式的无人机综合题库与考评 Web 应用。

## 🌟 核心特性
1. **多学科题库矩阵**：
   - 核心科目：**「无人机技术基础」**（内置 145 道全量真题，涵盖单选、多选、判断、填空、简答全题型）。
   - 5 大同级拓展科目：**低空小型无人飞行器探测反制技术及应用**、**雷达探测技术**、**无线电探测技术**、**光电探测原理**、**电磁干扰技术**，内置完整考点大纲体系与拓展接口。
2. **多模式考评体系**：
   - 刷题练习模式 / 背题速记模式切换
   - 全真模拟考试（100分制、45分钟倒计时、答题卡快速跳转、智能判卷）
   - 错题巩固本与重点收藏夹
   - 全局关键词智能搜索
3. **Word (.docx) 纯前端解析导入**：
   - 支持直接拖拽或选取本地 Word (.docx) 文档或纯文本；
   - 浏览器本地自动提取文字并正则结构化解析题目、选项与答案，离线可用、数据安全。
4. **完全本地存储 (LocalStorage)**：
   - 用户的做题记录、正确率、收藏夹与新导入的题库均保存在本地浏览器中，无需任何数据库或后端。

## 🚀 如何部署到 Netlify（10秒极速上线）

### 方法一：Netlify Drop 拖拽部署（最推荐，零命令）
1. 访问 Netlify 官方拖拽部署地址：[https://app.netlify.com/drop](https://app.netlify.com/drop)
2. 将本 `webapp-dist` 文件夹（或者将里面的全部文件压缩后的 `zip` 包）直接拖入页面中的虚线框中。
3. 等待几秒钟上传，Netlify 会立即为您生成一个专属公网网址（例如 `https://drone-expert-xxx.netlify.app`）。
4. 在 Netlify 后台的 **Site configuration** 中，您还可以自定义子域名或绑定您自己的独立域名。

### 方法二：通过 GitHub 持续集成部署
1. 将 `webapp-dist` 目录下的内容推送到您的 GitHub 仓库。
2. 在 Netlify 控制台选择 **Add new site** -> **Import an existing project** -> 关联该 GitHub 仓库。
3. **Publish directory** 填写根目录 `./`，点击 **Deploy** 即可。

## 📁 目录文件清单
- `index.html`：WebApp 主入口单页页面，采用现代化深色科技感 UI 与响应式布局。
- `app.js`：完整的答题引擎、判题逻辑、考试计时、错题本与 Word 解析业务逻辑。
- `embed_questions.js`：内嵌的 145 道全量真题初始数据。
- `data.js`：学科与考点大纲定义。
- `questions.json`：全量真题的纯 JSON 备份数据。
- `_redirects`：Netlify 静态单页路由配置文件。
